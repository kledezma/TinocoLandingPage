# Recordar para Defender la Democracia

Este proyecto tiene como objetivo crear una campaña educativa sobre la dictadura de los hermanos Tinoco en Costa Rica, con el fin de difundir su relevancia histórica y su impacto en la construcción de la democracia nacional.

## Contenido del Proyecto

- **Inicio**: Presenta el propósito del proyecto y la importancia de la memoria histórica.
- **Contexto Histórico**: Describe la dictadura de los hermanos Tinoco (1917-1919) y sus consecuencias en la democracia costarricense.
- **Línea de Tiempo**: Visualiza los eventos clave durante la dictadura.
- **¿Por qué importa hoy?**: Reflexiona sobre la relevancia de la democracia y la participación ciudadana.
- **Propuesta Innovadora**: Detalla la campaña "Recordar para defender la democracia" y sus recursos educativos.
- **Público Objetivo**: Define el público al que va dirigida la campaña, principalmente jóvenes y estudiantes.
- **Triple Hélice**: Explica la colaboración entre academia, gobierno y sector privado.
- **Cuádruple Hélice**: Incluye a la sociedad civil como actor en la difusión de la memoria histórica.
- **Aporte al Desarrollo Económico y Social**: Analiza cómo el conocimiento histórico contribuye al progreso del país.
- **Aprendizajes Obtenidos**: Resalta los aprendizajes clave del proyecto.
- **Conclusión**: Resume la importancia de recordar la dictadura y proteger la democracia.

## Instalación

1. Clona el repositorio:
   ```
   git clone <URL del repositorio>
   ```
2. Navega al directorio del proyecto:
   ```
   cd recordar-democracia
   ```
3. Instala las dependencias:
   ```
   npm install
   ```
4. Inicia la aplicación:
   ```
   npm start
   ```
